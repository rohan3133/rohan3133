## How I work

- **Metrics that fit the problem.** AUC, balanced accuracy and lift instead of defaulting to accuracy.
- **Leakage checks before celebration.** If a result looks too good, I look for the reason, and I say plainly what a model cannot do.
- **Reproducible by default.** One command regenerates every figure and table in a project.
